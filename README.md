# Original-submission code (snapshot)

This commit preserves the experiment code, results and figures of the original submission of
*On the Alignment Between Marginal Uncertainty Measures and Conditional Decision Risk in Estimator
Selection*. It is superseded by the revised code on the `main` branch.

Differences from the files used at submission: absolute paths of the author's machine were replaced
by paths relative to the repository root, and tools that only built or formatted the manuscript,
the manuscript itself and the data files are not included. The code is otherwise unchanged.
